# Knowledge base changelog

Every change to the KB goes through a pull request and is recorded here.
Version numbers: MAJOR.MINOR.PATCH
- PATCH: wording fixes to existing entries
- MINOR: new entries added
- MAJOR: entries removed or restructured (use a new folder, e.g. kb/v2)
