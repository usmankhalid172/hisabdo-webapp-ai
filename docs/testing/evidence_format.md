# AI/ML Testing Evidence Format

## Purpose

This document defines a consistent evidence format for AI/ML testing and evaluation in the HisabDo capstone project.

The purpose is to make testing results traceable and easy for Team Leads to review.

---

## Required Evidence Information

For every completed test, record:

1. Test ID
2. Feature name
3. Test date
4. Input
5. Expected result
6. Actual result
7. Test status (PASS/FAIL/BLOCKED) 
8. Evidence
9. Notes, if applicable
