## 12. Internet Requirement

Some features require an internet connection, including:

- Login and registration
- Cloud synchronization
- Account recovery

Supported local/offline guest functionality can be used without an internet connection. For signed-in users, supported customer, income, and expense records can synchronize with the cloud when connectivity is available.
