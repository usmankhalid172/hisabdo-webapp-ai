## Use Tools That Work Offline

Freelancers often work in varied environments — coffee shops, client offices, co-working spaces and home offices. An offline-first tool can help when connectivity is unreliable. HisabDo supports local offline use for supported features; signed-in users may synchronize supported records when connected. See the [Privacy Policy](https://hisabdo.app/privacy-policy) for how the current app handles records.
