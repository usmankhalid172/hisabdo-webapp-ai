## Faster Performance

Cloud-dependent apps must send requests to remote servers and wait for responses. This introduces latency — the slight delay between your action and the app's response. In a busy shop environment where you are serving multiple customers, these delays add up and create friction.

When an action can be completed locally, the app does not need to wait for a server response for that step. Actual performance still depends on the device, software and task; offline-first design alone does not guarantee that every app will feel faster.
