# HisabDo Feature Reference

## Customer records and ledgers

**Q: Can I manage customer records?**  
The FAQ says users can create customer profiles and review each customer's transaction history and running balance.

**Q: Can I track money customers owe me?**  
The FAQ describes tracking receivables with transaction history and an outstanding balance.

**Q: Can I track money I owe suppliers?**  
The FAQ describes tracking payables alongside customer receivables.

**Source:** [HisabDo FAQ](https://hisabdo.app/faq)

## Expenses and analytics

**Q: Can I record expenses?**  
The public pages describe expense tracking as a core use of the app.

**Q: What analytics are described?**  
The FAQ describes visual summaries of income trends, expense patterns, and outstanding balances.

**Sources:** [About HisabDo](https://hisabdo.app/about), [HisabDo FAQ](https://hisabdo.app/faq), [App overview](https://hisabdo.app/about-app)

## PDF statements

**Q: Can I create a PDF statement?**  
The FAQ says users can create PDF statements for a customer account or time period and share them from a phone. The app overview says a statement can show what is owed, what has been paid, and the running balance.

**Source:** [HisabDo FAQ](https://hisabdo.app/faq), [App overview](https://hisabdo.app/about-app)

## Voice entry

**Q: Does HisabDo support voice entry?**  
The FAQ and app overview describe voice input for creating records. Voice input is a feature description only; this reference does not promise a specific recognition accuracy, latency, supported dialect set, or on-device model.

**Sources:** [HisabDo FAQ](https://hisabdo.app/faq), [App overview](https://hisabdo.app/about-app)

## Languages and currencies

**Q: Which interface languages are listed?**  
The FAQ lists Urdu, English, Hindi, Arabic, and Roman Urdu.

**Q: Which currencies are listed?**  
The FAQ lists PKR, USD, and INR. A landing-page use-case mentions EUR and AED, so do not describe those as universally supported until the product owner confirms the scope.

**Source:** [HisabDo FAQ](https://hisabdo.app/faq); see validation sheet for the currency-scope discrepancy.

## Feature claims intentionally excluded

This cleaned reference omits promotional sidebars, customer testimonials, repeated calls to action, navigation/footer content, and numerical claims such as user counts, latency, voice accuracy, guaranteed calculation accuracy, and “zero” data leakage. The reviewed public pages do not provide independent supporting evidence for those figures or guarantees.
