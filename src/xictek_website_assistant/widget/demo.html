XICTEK Website Assistant — widget demo

This page stands in for a real xicteksystems.com page. The chat launcher in the bottom-right corner is the same xictek-widget.js that would be dropped onto the real site — nothing on this page is special-cased for the demo.

Requires uvicorn src.main:app --reload --port 8000 running from the repo root, and this file served (not opened via file://, so the widget's fetch() calls aren't blocked): e.g. from this widget/ folder run python -m http.server 5500 and open http://localhost:5500/demo.html.
