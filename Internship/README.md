My AI Chatbot
What I Built

I made a simple AI chatbot using Python. It takes input from the user and gives an AI response in the terminal.

Technology Used:
I used:

Python
VS Code
OpenAI API
OpenAI Python library
python-dotenv
How to Run It

First, install Python and the required libraries.

py -m pip install openai
py -m pip install python-dotenv

Then add the API key in the .env file.

After that, open the terminal in the project folder and run:

py chatbot.py

Then type a message after You: and the chatbot will give a response.

API Integration

I connected my Python chatbot with the OpenAI API using the OpenAI Python library.

The message entered by the user is sent to the API and the response is shown in the terminal.

I kept the API key in a .env file instead of writing it directly in the Python code.

What I Learned

I learned how to make a basic chatbot in Python. I also learned how to install Python libraries, use an API, use a .env file, and run a Python program from the VS Code terminal.

I also learned how to find and fix some errors while making the project.
