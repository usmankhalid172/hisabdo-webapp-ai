# Manual citation and conflict review checklist

For each answer containing citations:

- [ ] Every factual claim can be mapped to at least one cited article passage.
- [ ] Dates, names, quantities, and product details match the source exactly.
- [ ] Paraphrases preserve the source meaning and qualifications.
- [ ] No unsupported claim is added from prior conversation context.
- [ ] Each link uses HTTPS, the exact approved hostname, and an approved Blog/News path.
- [ ] The destination page loads and is the article described.

For each conflicting-source case:

- [ ] Both articles discuss the same underlying claim and are genuinely inconsistent.
- [ ] The response cites both sources.
- [ ] The response states what each source says and identifies the disagreement.
- [ ] Dates/publication or update times are checked before describing one as newer.
- [ ] The assistant does not silently select a winner without evidence.
- [ ] Follow-up turns remain grounded in current retrieved evidence, not merely prior assistant claims.
